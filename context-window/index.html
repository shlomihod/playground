What is real here, and sources
  • Real: the order and content of the system prompt (three cache tiers, SOUL.md first, memory and the profile line last) and the size of each part, measured from the hermes-agent source at commit 7520c4e8 (2026-10-15): identity and guidance text, the two DeepSeek-gated blocks, the index of 58 bundled skills, 37 of the 51 core tool schemas, the arxiv and llm-wiki skill bodies; the compaction rules (threshold 50% floored to 75% under 512K, 64K minimum, protected head and tail, tool-output stubs, skill pruning, summary budget, memory re-read when the system prompt is rebuilt); the 100-cell grid, status bar and colour bands of Hermes’s own /context and CLI; the model: Hermes’s model table gives deepseek-v4-flash a 1,000,000-token window (the KIT endpoint may report a smaller one; pick what your status bar shows), and the smaller windows stand for the model.context_length config cap. Tokens are Hermes’s own estimate: 4 characters ≈ 1 token. The tools in the session are Hermes’s registered tools; MCP tool names follow its mcp__server__tool scheme.
  • Estimated or sample: the two MCP servers’ schema sizes, the MEMORY.md and USER.md contents, the runtime-environment lines.
  • Scripted: the day itself. Its messages and token counts are illustrative, in the spirit of Anthropic’s Explore the context window simulation for Claude Code, which inspired this page.
  • Hermes docs: Context Compression and Caching, Prompt Assembly, Persistent Memory. Source file and line references are in this demo’s README.
