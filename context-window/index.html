Context Window

Everything an agent “knows” right now has to fit in one request. Watch Hermes Agent’s window fill up before you type, grow with every tool call, get compacted, and forget.

Mechanics and numbers come from the Hermes Agent source at commit 7520c4e8 (2026-10-15) and its docs. The coding session in part 2 is scripted: its messages and their token counts are illustrative; the rules that shrink it are real. Token counts use Hermes’s own rough estimator (4 characters ≈ 1 token).

3Compaction: what Hermes keeps, stubs, and summarizes

Hermes does not wait for the window to be full. Its ContextCompressor fires when the prompt reaches a threshold — default 50%, but floored to 75% on any window under 512K — and runs four phases. Drag the threshold, change the window in part 1, or press Compact now (the /compress command) at any step.

Why not just let it fill? Longer input is not free even before the hard limit. Chroma’s 2025 Context Rot report on 18 models: “Models do not use their context uniformly; instead, their performance grows increasingly unreliable as input length grows.” Compaction trades exact recall of old turns for a smaller, sharper window.

4Will it still remember? Place your bets

Seven things entered the window during the session. After a compaction, which does the model still have? Guess, then reveal: the answers come from the compressor’s actual rules (head/tail protection, regex-harvested anchors, verbatim user quotes, tool-output stubs, skill pruning, memory reload).

Where things actually live: four layers, one window

in the window

Live context

Bounded by the model’s window. Rewritten by compaction. The only thing the model sees.
in the window (snapshot)

MEMORY.md / USER.md

Up to 2,200 + 1,375 chars of curated facts, rendered into the system prompt once at session start. A mid-session save lands on disk but reaches the prompt only when it is rebuilt: next session, or right after a compaction.
outside the window

Session history (state.db)

Every message ever sent, including compacted ones (active=0, compacted=1). Unbounded, searchable with session_search, but only when the agent decides to look.
index in, bodies on demand

Skills

Names + one-line descriptions always sit in the prompt. A SKILL.md body enters only when skill_view loads it, and is pruned to a [SKILL_PRUNED: …] marker at compaction.
