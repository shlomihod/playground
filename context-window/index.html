What is real here, and sources
  • Real: what loads before you type and how big it is (measured from the hermes-agent source at commit 7520c4e8, 2026-10-15: identity and guidance text, the index of 58 bundled skills, 37 of the 51 core tool schemas, the repo’s own AGENTS.md as the project-rules example); the compaction rules (threshold 50% floored to 75% under 512K, 64K minimum, protected head and tail, tool-output stubs, skill pruning, summary budget, memory reloaded when the system prompt is rebuilt); the 100-cell grid, status bar and colour bands of Hermes’s own /context and CLI; the model: Hermes’s model table gives deepseek-v4-flash a 1,000,000-token window, and the smaller windows in the selector are what its model.context_length config cap would make of it. The nine tools in the session (read_file, search_files, terminal, patch, skill_view, memory, delegate_task, web_search, web_extract) are Hermes’s registered tools. Tokens are Hermes’s own estimate: 4 characters ≈ 1 token.
  • Scripted: the coding session itself. Its messages and token counts are illustrative, in the spirit of Anthropic’s Explore the context window simulation for Claude Code, which inspired this page.
  • Hermes docs: Context Compression and Caching, Prompt Assembly, Persistent Memory. Source file and line references are in this demo’s README.
